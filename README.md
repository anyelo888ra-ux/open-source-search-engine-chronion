# 🔍 Chronioñ Search

¡Bienvenido a **Chronioñ Search**! El motor de búsqueda open-source, ultraligero y centrado en la privacidad diseñado para integrarse con la suite de navegadores **Chronioñ** (PC y Android).

---

## 🚀 Características Principales

* **Minimalista y Rápido:** Interfaz limpia sin anuncios molestos ni rastreadores.
* **Integración Nativa:** Optimizado para funcionar directamente con Chronioñ Browser en Python y Kotlin.
* **Dominio Personalizado:** Desplegado mediante GitHub Pages y sincronizado con `chronion-search.duckdns.org`.
* **Código Abierto:** Licencia MIT para que la comunidad pueda colaborar y mejorar el indexador.

---

## 🛠️ Estructura del Proyecto

* `index.html`: Portada principal del buscador.
* `search.html`: Interfaz dinámica para visualizar los resultados de búsqueda.
