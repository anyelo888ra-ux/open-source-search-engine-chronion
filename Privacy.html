Política de Privacidad

Última actualización: Noviembre 2026 • Chronioñ Search Project

Resumen de privacidad: Chronioñ Search es un motor de búsqueda privado y de código abierto alojado en GitHub Pages. No rastreamos tus búsquedas, no almacenamos tu dirección IP en servidores centrales y no vendemos tu información a terceros.

1. No recopilación de datos personales

Chronioñ Search opera bajo un principio fundamental de privacidad desde el diseño (Privacy by Design). Cuando realizas una consulta de búsqueda:

  • Sin registro de consultas: No guardamos tus términos de búsqueda en ningún servidor ni base de datos centralizada.
  • Sin perfiles de usuario: No creamos perfiles publicitarios ni rastreamos tus hábitos de navegación.
  • Sin Cookies de seguimiento: No empleamos cookies de rastreo ni tecnologías similares de perfilado.

2. Modo Incógnito (Privacidad Total)

Chronioñ cuenta con un Modo Incógnito diseñado para no dejar rastro:

  • No guarda el historial de búsqueda ni el chat en LocalStorage.
  • Al cerrar la pestaña, todos los datos se borran de la memoria.
  • El Ban-Bot-18 no actúa en este modo (excepto si detecta contenido +18).

3. Procesamiento local y Modo IA

El módulo de Inteligencia Artificial (Modo IA) de Chronioñ funciona 100% en el lado del cliente (tu navegador) utilizando JavaScript ejecutable de forma local. Esto significa que:

  • No requerimos ni utilizamos API Keys externas que recopilen tus peticiones en servidores de terceros.
  • Tus datos no salen de tu propio navegador para entrenar modelos de IA externos.
  • El historial del chat se guarda en tu propio dispositivo (LocalStorage) y puedes borrarlo en cualquier momento.

4. El Ban-Bot-18 y la Moderación

Chronioñ cuenta con un sistema de moderación global (Ban-Bot-18) que detecta búsquedas de contenido +18 en todos los HTML. Si detecta una infracción:

  • Bloquea la pantalla del usuario.
  • Registra la IP simulada del usuario (puede ser real si se usa la API de ipify).
  • Aplica un baneo de 24 horas en LocalStorage.
  • El Ban-Bot no envía datos a servidores externos. Todo se procesa localmente.

5. Consultas a la Web Abierta (Wikipedia y DuckDuckGo)

Para mostrar los resultados en pantalla, el navegador solicita los datos directamente desde fuentes públicas (Wikipedia, DuckDuckGo, YouTube, Google News) mediante solicitudes cifradas (HTTPS). Estas peticiones únicamente reciben los datos necesarios para generar la lista de resultados en tu pantalla en tiempo real.

6. Registro de URLs (Comunidad)

El sistema de registro de URLs permite a los usuarios enviar sus sitios web a través de Pull Requests en GitHub. Chronioñ no recopila datos personales en este proceso; solo se almacena la URL, el título y la descripción proporcionados voluntariamente por el dueño del sitio.

7. Código Abierto y Transparencia

Todo el código fuente de Chronioñ Search es completamente transparente y está disponible en GitHub. Cualquier usuario o desarrollador puede auditar el código para verificar que cumple con estos estándares de privacidad.
