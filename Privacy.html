Política de Privacidad

Última actualización: Septiembre 2026 • Chronioñ Search Project

Resumen de privacidad: Chronioñ Search es un motor de búsqueda privado y de código abierto alojado en GitHub Pages. No rastreamos tus búsquedas, no almacenamos tu dirección IP y no vendemos tu información a terceros.

1. No recopilación de datos personales

Chronioñ Search opera bajo un principio fundamental de privacidad desde el diseño (Privacy by Design). Cuando realizas una consulta de búsqueda:

  • Sin registro de consultas: No guardamos tus términos de búsqueda en ningún servidor ni base de datos centralizada.
  • Sin perfiles de usuario: No creamos perfiles publicitarios ni rastreamos tus hábitos de navegación.
  • Sin Cookies de seguimiento: No empleamos cookies de rastreo ni tecnologías similares de perfilado.

2. Procesamiento local y Modo IA (Pure JS)

El módulo de Inteligencia Artificial (Modo IA) de Chronioñ funciona 100% en el lado del cliente (tu navegador) utilizando JavaScript ejecutable de forma local. Esto significa que:

  • No requerimos ni utilizamos API Keys externas que recopilen tus peticiones en servidores de terceros.
  • Tus datos no salen de tu propio navegador para entrenar modelos de IA externos.

3. Consultas a la Web Abierta

Para mostrar los resultados en pantalla, el navegador solicita los datos directamente desde fuentes públicas de búsqueda mediante solicitudes cifradas (HTTPS). Estas peticiones únicamente reciben los datos necesarios para generar la lista de resultados en tu pantalla en tiempo real.

4. Código Abierto y Transparencia

Todo el código fuente de Chronioñ Search es completamente transparente y está disponible en GitHub. Cualquier usuario o desarrollador puede auditar el código para verificar que cumple con estos estándares de privacidad.
